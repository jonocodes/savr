This fixture contains one image that resolves and one that does not, so the ingestion pipeline can be checked end to end. When an image cannot be downloaded it must be replaced with a local placeholder rather than left pointing at a remote URL. The unique marker FailedImageFixture appears here to help the test confirm it loaded the right article, and there is enough prose for Readability to keep the body.
